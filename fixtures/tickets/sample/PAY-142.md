# PAY-142 Allow partial refunds

## Description

Support agents currently have to refund an entire order even when only one item
came back damaged. They should be able to refund part of an order instead.

The refund should show up on the customer's account quickly and they should get an
email about it. Finance has asked that this be tracked properly.

## Acceptance Criteria

- Agent can select an order and enter a refund amount
- Agent can add a reason
- The customer is notified
- The refund appears in the order history
