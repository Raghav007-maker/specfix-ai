# RPT-19 Export transactions to CSV

## Description

Finance is copying numbers out of the transactions table by hand every month. Give
them an export button that produces a CSV they can open in Excel.

They want all the fields that are on screen plus the customer details so they can
reconcile against the bank statement.

## Acceptance Criteria

- Export button on the transactions page
- CSV contains one row per transaction
- Columns match the on-screen table
- File downloads with a sensible filename
